# 🕵️‍♂️ AI Mystery Room

An AI-powered interactive web application where users investigate and solve dynamic criminal mysteries generated by Google Gemini. Players inspect crime scenes, interrogate suspect alibis, request precinct hints, and deduce the true perpetrator.

Built with **React**, **Vite**, **Tailwind CSS**, **Node.js**, **Express**, **MongoDB / Mongoose**, and **Google Gemini API**.

---

## 🌟 Key Features

- **Dynamic Gemini Case Generation:** Generates infinite, logically watertight murder and heist mysteries across three difficulty levels (**Easy**, **Medium**, **Hard**).
- **Zero Solution Leaks (Security-First):** The true culprit, motive, and solution narrative are strictly isolated on the backend. Active game queries never expose the perpetrator to the browser client or network tab.
- **Interactive Crime Scene & Evidence Discovery:** Click to examine crime scene hotspots, unlocking forensic analysis notes and awarding **+5 points** per clue.
- **Precinct Guidance System:** Progressive hint reveals with score penalty warnings (**-10 points** per hint).
- **Judicial Indictment Chamber:** Select your prime suspect from the lineup, document your deductive theory, and file a formal accusation.
- **Declassified Case Dossier:** Unlocks the culprit's full confession, forensic reconstruction, and scorecard factoring base difficulty bonus, clues discovered, and hints used (minimum floor of 0).
- **Tactile Audio Experience:** Zero-dependency synthesized audio cues via the Web Audio API for clue inspections, radar pings, gavel thumps, and victory fanfares.

## 🛠️ Architecture & Tech Stack

### Frontend (`/client`)
- **Framework:** React 19 + Vite
- **Styling:** Tailwind CSS (Dark Noir theme, custom glassmorphism)
- **Routing:** React Router v6
- **HTTP Client:** Axios
- **Icons & Effects:** Lucide React, Canvas Confetti, Web Audio API

### Backend (`/server`)
- **Server:** Node.js + Express
- **Database:** MongoDB + Mongoose (with automatic in-memory fallback for zero-config offline development)
- **AI Integration:** `@google/genai` (Gemini SDK with JSON schema mode)
- **Validation:** Zod runtime validation
- **Security:** CORS, input sanitization, hidden Mongoose fields (`select: false`)

## 🚀 Quick Start Guide

### 1. Prerequisites
- **Node.js**: v18.0.0 or higher
- **npm**: v9.0.0 or higher
- *(Optional)*: MongoDB Atlas connection string and Gemini API Key. If not provided, the application runs seamlessly using built-in procedural mysteries and an in-memory database store!

### 2. Backend Setup
```bash
cd server
npm install

# Configure environment variables
cp .env.example .env
```

Edit `server/.env`:
```env
PORT=5000
MONGODB_URI=mongodb://localhost:27017/ai_mystery
GEMINI_API_KEY=your_gemini_api_key_here
CLIENT_URL=http://localhost:5173
```

Start the backend server:
```bash
npm run dev
# Server will run on http://localhost:5000
```

### 3. Frontend Setup
In a new terminal window:
```bash
cd client
npm install
npm run dev
# Frontend will run on http://localhost:5173
```

Visit **http://localhost:5173** in your browser!

## 📡 REST API Reference

| Method | Endpoint | Description |
| :--- | :--- | :--- |
| `POST` | `/api/cases` | Generate a new mystery (`{ premise, difficulty }`) |
| `GET` | `/api/cases` | List recent mystery cases |
| `GET` | `/api/cases/:id` | Retrieve an active case (solution redacted) |
| `POST` | `/api/cases/:id/clues/:clueId/discover` | Inspect a crime scene clue (+5 pts) |
| `POST` | `/api/cases/:id/hints` | Request next precinct hint (-10 pts) |
| `POST` | `/api/cases/:id/accuse` | Submit formal accusation (`{ suspectId, deduction }`) |
| `GET` | `/api/cases/:id/result` | Retrieve full result dossier (403 if still active) |
| `GET` | `/api/health` | Service health check |

## 🚢 Deployment Guide

### Deploy Backend (Render / Railway / Fly.io)
1. Push your repository to GitHub.
2. In **Render** or **Railway**, create a new Web Service pointing to root directory `server/`.
3. Set Build Command: `npm install`
4. Set Start Command: `npm start`
5. Configure Environment Variables:
   - `PORT`: `5000`
   - `MONGODB_URI`: Your MongoDB Atlas URI (`mongodb+srv://...`)
   - `GEMINI_API_KEY`: Your Google AI Studio API key
   - `CLIENT_URL`: Your deployed frontend Vercel URL
   - `NODE_ENV`: `production`

### Deploy Frontend (Vercel)
1. In **Vercel**, import your GitHub repository.
2. Set Root Directory to `client`.
3. Framework Preset: **Vite**.
4. Configure Environment Variable:
   - `VITE_API_URL`: Your deployed backend URL (e.g., `https://ai-mystery-server.onrender.com/api`)
5. Deploy!
